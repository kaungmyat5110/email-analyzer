# email-analyzer
1 Reads the file: Open and reads the file(mbox-short.txt) line by line.
2 Extracts emails: Filters and extracts email addresses from lines starting with "From ".
3 Counts occurrences: Uses a Python dictionary to track and count how many times each email address appears.
4 Displays results: Prints the total number of emails processed, identifies the emails address with the highest count.
